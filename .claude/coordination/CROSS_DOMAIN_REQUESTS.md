# 도메인 간 변경 요청

한 도메인에서 발생했지만 다른 도메인의 작업이 필요한 변경 요청을 추적합니다.

## 요청 흐름

1. 요청 도메인 에이전트가 이 파일에 요청 등록
2. 대상 도메인 에이전트가 작업 시작 전 이 파일 확인
3. 처리 완료 후 상태를 `완료`로 변경
