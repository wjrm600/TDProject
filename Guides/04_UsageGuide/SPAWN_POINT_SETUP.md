# 스폰 포인트 시스템 - 레벨 세팅 가이드

## 개요

이 가이드는 Unreal Engine에서 AOS 게임의 스폰 포인트를 설정하는 방법을 설명합니다.

## 시스템 구조

### 스폰 포인트 란?
- **AAOSSpawnPoint**: 캐릭터가 게임 시작 시 배치되는 위치
- 각 스폰 포인트는 **팀(Team1/Team2)**과 **스폰 순서(Index)**를 가짐
- 같은 팀이라도 여러 개의 스폰 포인트를 만들 수 있음

### 배치 원리

1. **플레이어가 준비 단계에서 라인 배치 결정**
   ```
   예: [Top, Mid, Bottom, Mid]
   → 첫 번째 캐릭터는 Top, 두 번째는 Mid, 세 번째는 Bottom, 네 번째는 Mid
   ```

2. **게임 시작 시 각 캐릭터를 해당 라인에서 가장 가까운 스폰 포인트에 배치**
   ```
   캐릭터 1 (Top 라인) → Top 라인 스폰 포인트 1
   캐릭터 2 (Mid 라인) → Mid 라인 스폰 포인트 1
   캐릭터 3 (Bottom라인) → Bottom 라인 스폰 포인트 1
   캐릭터 4 (Mid 라인) → Mid 라인 스폰 포인트 2
   ```

## 레벨 에디터에서 스폰 포인트 설정

### 1단계: 스폰 포인트 배치

1. **Content Browser**에서 **AAOSSpawnPoint** 클래스 찾기
2. 레벨에 드래그하여 배치
   - Team1 (Red) 진영: 맵의 한쪽
   - Team2 (Blue) 진영: 맵의 다른 쪽

### 2단계: 스폰 포인트 설정

각 스폰 포인트를 선택한 후 **Details** 패널에서:

#### Team1 (Red) 진영 - 탑 라인
- **Team**: Team1
- **Spawn Index**: 0, 1, 2, 3... (순서대로)
- **Location**: 탑 라인 경로상에 배치

예시:
```
탑 라인 스폰 포인트 1
  - Team: Team1
  - Spawn Index: 0
  - Location: (1500, 1500, 0)

탑 라인 스폰 포인트 2
  - Team: Team1
  - Spawn Index: 1
  - Location: (1400, 1400, 0)
```

#### Team1 (Red) 진영 - 미드 라인
```
미드 라인 스폰 포인트 1
  - Team: Team1
  - Spawn Index: 0
  - Location: (1500, 0, 0)

미드 라인 스폰 포인트 2
  - Team: Team1
  - Spawn Index: 1
  - Location: (1400, 0, 0)

미드 라인 스폰 포인트 3
  - Team: Team1
  - Spawn Index: 2
  - Location: (1300, 0, 0)
```

#### Team1 (Red) 진영 - 바텀 라인
```
바텀 라인 스폰 포인트 1
  - Team: Team1
  - Spawn Index: 0
  - Location: (1500, -1500, 0)

바텀 라인 스폰 포인트 2
  - Team: Team1
  - Spawn Index: 1
  - Location: (1400, -1400, 0)
```

#### Team2 (Blue) 진영 - 동일한 방식으로 반대편에 배치
```
탑 라인 스폰 포인트 1
  - Team: Team2
  - Spawn Index: 0
  - Location: (-1500, -1500, 0)

... (이하 동일)
```

## 캐릭터 배치 예시

### 예시 1: 탑 2마리, 미드 1마리, 바텀 1마리
```

게임 시작 시:
1. 첫 번째 캐릭터 → Top 라인 스폰 포인트 0
2. 두 번째 캐릭터 → Top 라인 스폰 포인트 1
3. 세 번째 캐릭터 → Mid 라인 스폰 포인트 0
4. 네 번째 캐릭터 → Bottom 라인 스폰 포인트 0
```

3. 세 번째 캐릭터 → Mid 라인 스폰 포인트 1

## 스폰 포인트 배치 권장사항

1. **각 라인당 최소 4개 이상의 스폰 포인트 배치**
   - 한 라인에 4마리 캐릭터가 모두 배치될 수 있으므로

2. **라인의 시작점 근처에 배치**
   - 캐릭터들이 라인을 따라 순찰하기 시작하는 위치

3. **스폰 포인트 간격 유지**
   - 캐릭터들이 서로 겹치지 않도록 충분한 거리 유지 (200~300 units)

4. **팀별로 대칭적으로 배치**
   - Team1과 Team2의 스폰 포인트가 맵의 양쪽에 대칭적으로 배치

## 코드에서 스폰 포인트 사용 (선택사항)

### 블루프린트에서 게임 시작
```
1. 각 플레이어가 캐릭터 배치 선택
2. "Start Game" 버튼 클릭
3. AOSGameMode::SpawnCharacter() 자동 호출
4. 캐릭터들이 지정된 스폰 포인트에 배치
5. AI 컨트롤러 시작 및 라인 순찰 시작
```

## 문제 해결

### 캐릭터가 스폰되지 않는 경우
- 스폰 포인트가 올바르게 배치되었는지 확인
- 해당 라인의 스폰 포인트가 충분한지 확인
- AOSGameMode가 월드에 배치되어 있는지 확인

### 캐릭터가 잘못된 위치에 스폰되는 경우
- Spawn Index가 올바르게 설정되었는지 확인
- Team 설정이 정확한지 확인
- 스폰 포인트의 Location이 맞는 라인상에 있는지 확인

## 다음 단계

3. 각 캐릭터의 AssignedLane 설정 또는 플레이어가 준비 단계에서 선택하도록 구현
4. 게임 시작 시 자동으로 스폰 포인트로 캐릭터 배치

---

**참고**: 스폰 포인트 시스템은 자동으로 BeginPlay 시점에 AAOSGameMode가 모든 스폰 포인트를 등록합니다.
