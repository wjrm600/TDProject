# 애니메이션 제작 기획 템플릿 (Alex 골든 템플릿용)

> **목적**: 사용자가 "이런 모션을 원한다"를 자유 서술로 적으면, Claude 가 그걸 **하이브리드 애니 파이프라인**
> (Blender 리타깃+수정 → 루트모션/타이밍/접지 베이크 → UE 재임포트 → 몽타주 + AnimNotify)의
> 기술 파라미터로 번역해 제작합니다.
>
> **사용법**: 아래 [블랭크 템플릿](#블랭크-템플릿-복사해서-작성)을 모션 1개당 하나씩 복사해 채운 뒤,
> "이 모션 만들어줘"라고 주세요. 채워진 예시([R 슬램](#작성-예시--alex-r--demacian-justice-완료작))를
> 먼저 보면 어느 수준으로 적으면 되는지 감이 옵니다.
>
> **꼭 비워두지 말 것 3가지** (R 슬램이 이 3개로 결정됐습니다):
> 1. **구간별 타이밍 비트** (윈드업 → 실행 → 임팩트 → 회복, 대략 초 단위) → 동작 속도 곡선이 됨
> 2. **임팩트 순간** = "정확히 언제 적을 때리나" (예: *검 끝이 땅에 닿는 순간*) → 데미지 노티파이 + 바닥 정렬 기준
> 3. **신체가 땅을 떠나는가** (도약/돌진이면 높이·거리) → 루트모션 + 몸 높이 곡선
>
> 나머지(본 회전, IK, FBX 축 설정 등)는 Claude 가 알아서 처리합니다. 그림으로 그려도 되고,
> 참고 영상/스크린샷이 있으면 **가장 정확**합니다 (아래 "참고 자료" 칸).

## 작성 팁 — 이렇게 적으면 한 번에 나옵니다

| 적는 법 | 좋음/나쁨 | 이유 |
|---------|:---------:|------|
| "착지하는 순간 검 끝이 땅에 닿게" | ✅ | 임팩트를 신체 이벤트(착지)에 묶어줌 → 자동 정렬 가능 |
| "검을 위로 들었다가 내려쳐" + 대략 타이밍 | ✅ | 윈드업/다운스윙 구간이 분리됨 |
| "멋있게 휘둘러" | ❌ | 타이밍·임팩트 정보 없음 → 되물어봐야 함 |
| 참고 영상 링크 / 스크린샷 | ✅✅ | 포즈를 직접 보고 베이스 소스를 고를 수 있음 |
| "1초쯤? 잘 모르겠음" | ✅ | **모르면 비워도 됨** — Claude 가 종류별 기본값(공격~1s, 궁~1.5s) 제안 |
