# 밸런스 변경 이력 (06_BalanceLog)

이 폴더는 `design-balance` 에이전트가 게임 수치를 변경할 때 기록하는 이력 폴더입니다.

## 기록 형식

파일명: `YYYY-MM-DD_밸런스패치.md`

```markdown
# YYYY-MM-DD 밸런스 패치

## 변경 내용
- BP_Character.MaxHealth: 100 → 120 (사유: 타워 공격에 너무 빨리 사망)
- BP_Team1Tower.AttackDamage: 20 → 15 (사유: 캐릭터 체력 증가에 맞춤)

## 테스트 결과
- 변경 전 평균 게임 시간: 8분
- 변경 후 평균 게임 시간: 12분

## 추가 관찰
- 타워 생존율 개선됨
- 커맨드센터 생존 시간 증가
```

## 현재 이력

아직 기록된 변경사항 없음.
